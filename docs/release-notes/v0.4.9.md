# v0.4.9 — correct Codex context usage

The chat footer now measures Codex’s latest reported context usage against its reported context window. Previously it used cumulative tokens processed across every request, repeatedly counting the same history and often leaving the meter stuck at 100%.

The meter can now decrease when Codex reports a smaller context after compaction. This applies to conversations run through the Codex driver, including ChatGPT subscription sign-in.

The fix passed all 243 provider unit tests and full repository CI. A regression test reproduced the inflated reading before the fix and checks that context can shrink while cumulative usage continues growing.

After upgrading, restart the workspace once active turns have finished. Existing conversations refresh their saved context reading on the next Codex usage notification.
