# v0.6.1 — long conversations open at once

**Opening a long conversation no longer stalls the workspace.** Every diff in a conversation used to be syntax-highlighted again each time you opened it, before anything was drawn — most of a second for a big one, and about three on a busy machine, with every key in every terminal waiting behind it. Now the conversation appears straight away and the colours fill in a moment later, starting with what is on screen; nothing moves when they do. The conversations you used most recently are coloured ahead of time at startup, so even the first visit is quick. Switching into a large conversation went from up to three seconds to about a tenth of one, and startup to the first screen from 1.2 s to 0.6 s.

**Background agents show as soon as the turn ends.** A sub-agent still running when the agent finished its answer is moved into the background, and the project panel did not show it until you sent another message — at which point it appeared at once. It is shown when the turn ends now.

**Screenshots an agent read are kept.** Pictures a tool returned were saved in the system's temporary folder, which macOS clears, so older conversations slowly lost them. They are stored with the rest of neosh's state now, and pictures still in the temporary folder are moved there the next time the workspace starts.

Also: opening the model picker no longer pauses the workspace while the keychain is read.

After upgrading, run `neosh stop` and start `neosh` again: a running workspace keeps executing the old binary.
