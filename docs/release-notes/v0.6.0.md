# v0.6.0 — a terminal for one computer, models without a release, and faster everywhere

**A terminal can be for one computer.** `neosh connect linux-box` opens a terminal for that machine. Its project panel shows only that machine's projects, drawn as if it were your own, with `@lb linux-box` dim beside the `PROJECTS` heading. `^N` and `+ Add project` start there, and it opens in the newest conversation over there. `neosh ls` lists the computers you can reach, and plain `neosh connect` asks. When another computer is connected, plain `neosh` asks **which computer?**; `swarm.device` (on the *Computers* page of `/settings`) makes the answer the default, and `/device` changes it from inside. Nothing stops when a window is pointed elsewhere: turns on the other machines keep running.

**New models arrive without a release.** neosh now follows [t3code](https://github.com/pingdotgg/t3code)'s model manifest, which tracks the `claude`, `codex` and `agy` CLIs and is updated the day a model ships. A running workspace checks it every six hours and when you press `^R` in the model picker. It can only mark models current or superseded, add new ones, and say which CLI release a model needs. A new model takes its rung, tagline and settings from the model it succeeds, and never its price. Models that need a newer CLI show up greyed out with the command that unlocks them. This release already includes Claude Sonnet 5.5, Claude Haiku 5.5 and the GPT-6 models for `codex`. `models.update = false` turns the checking off.

**Cloning is on `^O`.** Adding a project has a **Clone a repository…** row: give it a URL, `git@…`, or just `owner/repo`, choose where it goes, and you land in it. Pasting an address straight into the field still works, and `^K git.clone` asks for an address when given none.

**Faster.** Streaming a long answer with a big code block went from over two minutes at a full core to under a second; code now streams a line at a time. Typing reaches the screen in about 5 ms instead of 26, moving in the project panel takes 10 ms instead of 24, idle CPU went from 2.1% to 0.2%, memory after a long answer from 120 MB to 77 MB, and the binary from 102 MB to 70 MB.

Also:
- `neosh prompt "…"` is how to start with a question. `neosh why is this slow` is now refused with the line it meant, so a mistyped subcommand is no longer sent to a model.
- A pull request opened from somebody's fork no longer appears on your own branch's row. A stranger's closed PR from their fork's `main` used to show as `#843 closed` on your main checkout.

For plugin authors, 0.6.0 is a breaking release of the Rust crates: `ViewInfo` has a `device` field, and `ApiCall` and `PluginEvent` have new variants. `neosh.view.device()`, `setDevice()` and `onDevice()` are the new calls, and the `neosh.models.changed` event fires when the model list changes.

After upgrading, run `neosh stop` and start `neosh` again: a running workspace keeps executing the old binary.
